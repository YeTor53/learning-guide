## 1. 你的原话（逐条拆开）

> 现在的焦点还是诡异，应该是**每个人尝试均分屏幕**，然后尽量**保证铺满**；**举手的人可以在被管理确认后得到焦点**；**在得到焦点时这个人的框放大**；**举手的人框会一直边框闪烁**；这时**有管理权限的可以选择给他焦点或强制他放下手**；**房主可以直接把自己放到焦点位置**；**房管想获得焦点需要另一个非本人批准**；**焦点可以自己退出**（获得焦点时退出焦点的按钮替换举手）；**房主的举手按钮则默认时取得焦点按钮**；**进入视频后，也应该有一个麦克风悬浮键**用来像没进入视频时候一样显示声波效果。

## 2. 现状（r004 已落地的事实，供你对照）

| 项 | 现状 |
| --- | --- |
| 布局 | `stageLayout.ts` 是唯一事实源：**焦点格 + 右侧 rail**（焦点格居中 16:9，rail 缩格 176×99，k≤3 单列 / 4~6 双列 / 7 三列，窄屏或视口宽<高时改底部横条） |
| 焦点来源 | 共享 > 手动焦点 > 说话者 > 自己（ADR-0014）；手动焦点写 `room_focus` 事件流表 |
| 举手 | `room_hand_raises` 表 + DataChannel `lg.hands` 广播；**他人放下手**已支持（Host/Moderator） |
| 徽标 | 举手/焦点/共享都有 chip（`chip-focus` / `chip-share`），静音有麦标（r006） |
| 麦克风 | 设备条上的麦克风按钮（房内）；**没有**声波/音量指示（设备检查页有） |

## 3. 我理解的目标（待你确认）

1. **布局改成均分铺满**：不再「一个大焦点格 + 一排小格」，而是所有人**尽量等分**并把可用区域铺满。
2. **举手 → 管理确认 → 得焦点**：举手只是一个申请，**由管理身份（房主/协管）确认**才给焦点。
3. **得焦点的人格子放大**（在均分基础上略大，或在均分里给它一个更大的份）。
4. **举手未处理期间，本人格子边框持续闪烁**（提醒全场 + 提示管理）。
5. **管理动作二选一**：给焦点 / 强制放下手（后者已有）。
6. **房主**：可以直接把自己置为焦点（一键）。
7. **协管**：想得焦点需**另一个非本人**的管理身份批准（即协管的「取得焦点」是一次申请）。
8. **焦点可自行退出**；**处于焦点时**，举手按钮位置换成「退出焦点」按钮。
9. **房主**的举手按钮**默认就是「取得焦点」**（不是举手）。
10. **房内麦克风悬浮键**：进视频后也能像设备检查页那样看到**声波/电平**反馈。

## 4. 与作业的关系（提醒）

作业必做写的是「焦点发言：Host/Moderator 指定焦点发言人，画面放大；取消后恢复；**与屏幕共享同时存在时需写明优先级规则**」——当前实现已满足。本轮是**体验重做**，会动到 r004 的布局与优先级口径 → 需要新 ADR（覆盖/修订 ADR-0014 的布局部分，优先级规则保留）。

## 5. 待拍板（回数字；例 `2 1 1 1 1 1 1 1 2 1 1`）

| # | 问题 | 选项 | 建议 |
| --- | --- | --- | --- |
| Q1 | 工具栏位置（你刚问的） | ① 保持现状（hero 之下、列表之上）② **改回 hero 之上**（r004 的位置，首屏能筛） ③ 两处都放（hero 上放状态筛选、列表上放主题/刷新） | ②（你上次的「太下」就是为这个） |
| Q2 | 布局口径 | ① **纯均分铺满**（无特殊大格；焦点只做强调）② 均分 + 焦点格**略大**（约 1.4 倍）③ 仅一人时铺满、多人均分 | ② |
| Q3 | 均分算法 | ① 按人数选最接近正方形的最优行列 + 填满剩余空间（建议）② 固定列数（1/2/3/4 递增） ③ 保持现阶梯只改比例 | ① |
| Q4 | 举手闪烁 | ① 3px 强调色呼吸边框，1.2 秒一循环（建议）② 更慢（2 秒）更含蓄 ③ 只在管理端闪烁 | ① |
| Q5 | 「管理确认」在哪操作 | ① 该成员格子上的角标按钮（给焦点/放下手）（建议）② 成员抽屉里 ③ 两处都给 | ③ |
| Q6 | 协管取得焦点需「另一个非本人批准」 | ① 点「取得焦点」→ 其他管理身份（房主或另一协管）在成员面板看到**申请**并批准（建议）② 房主单独批准（协管之间不能互批）③ 不需要批准，协管与房主同权 | ① |
| Q7 | 焦点「自动让位」规则 | ① 保留现有优先级（共享 > 手动焦点 > 说话者 > 自己）（建议）② 手动焦点**永不**被说话者顶掉 ③ 共享时焦点格也保留（共享缩成小格） | ① |
| Q8 | 默认是否给说话者自动焦点 | ① 保留（现有行为，画面会随说话人切换）（建议）② 关闭自动，必须人工指定 | ① |
| Q9 | 麦克风悬浮键 | ① 复用设备条上的麦克风按钮，**给它加声波环**（建议）② 新增独立悬浮键（可拖，默认右下）③ 只在静音时出现 | ① |
| Q10 | 声波实现 | ① `useTracks` 的本地/远端的 `audioLevel`（LiveKit 内置，零依赖，建议）② Web Audio AnalyserNode（更细腻，代码更多） | ① |
| Q11 | 屏幕共享与均分的关系 | ① 共享时**共享画面独占大部分区域**，人像缩成一行小格（建议，作业要求「共享为主区域」）② 共享也参与均分 | ① |
