**已落地**：均分铺满几何（含两个「没铺满」真问题的修复）、FLIP 动效 + 令牌、`（你）`标识、焦点权限三分流 + 申请—他人批准（后端强约束 + 前端面板）、举手「给焦点/放下手」闭环、举手闪烁。
