## 两栏清单

**已落地**：均分铺满几何（含两个「没铺满」真问题的修复）、FLIP 动效 + 令牌、`（你）`标识、焦点权限三分流 + 申请—他人批准（后端强约束 + 前端面板）、举手「给焦点/放下手」闭环、举手闪烁。

**未闭合**：① 声波电平数字（E11 部分）② SSE 实时通道（r011）③ 焦点者离开时的申请清理只有后端 `cancel_pending` 函数、未接事件 ④ 说话者自动焦点的「30 秒交替说话 ≤3 次」未做端到端演练（防抖/冷却/保护期已实现）。
