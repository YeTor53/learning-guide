## 5. 成本与影响面速查

| 选项 | 影响面 |
| --- | --- |
| Q1 扩到 A 段全部 | 6~8 个文件各加一行 `<QuoteLine slot=… />`（纯新增，风险低） |
| Q2② 替换原文 | 涉及删除现有文案 → 属界面文案变更，要走视觉契约与验收（截图对账），且「解释性文案」被删后，新用户可能不知道房间能干什么 |
| Q4②/③ | 纯前端改动（选句函数） |
| Q4④ 场景化 | 语录池加 `tag` 字段 + 槽位→场景映射表 + 单测（同日稳定） |
| Q5 扩池 | 只改 `content/philosophy.ts`；需你确认内容口径（真实语录、不编造） |
| Q6② 出处 | 池子每条加 `source` 字段 + 呈现多一行小字 |
| Q8② 换一句 | 浮窗加按钮 + 组件接受「手动指定」状态（本地 state，不落库） |
| Q9② 后端接口 | 新表/接口/管理入口 = 新轮次 + 迁移 + 测试（成本最高） |
