# CR r010-01：multipart 上传需要新增依赖 `python-multipart`

## 触发
- 位置：`backend/app/api/routers/transcripts.py`（`POST /api/rooms/{room_id}/transcripts` 用 `File(...)` + `Form(...)`）；`backend/tests/test_transcripts_api.py`
- 现象（原样）：
  跑 `python -m pytest backend/tests/test_transcripts_api.py -q` → 13 个上传用例**全部 ERROR**，原文：
  `RuntimeError: Form data requires "python-multipart" to be installed. You can install "python-multipart" with: pip install python-multipart`
  实测环境（conda `learningguide`）`pip list` 无 multipart 相关包：`fastapi 0.141.1 / starlette 1.6.0 / aiohttp 3.14.3 / psycopg 3.3.5`。
- 冲突（引设计原文）：`docs/rounds/r010-transcription/design.md` §2.5「POST /api/rooms/{room_id}/transcripts ｜ **multipart**：`file`(音频) + `segmentIndex` + `startedAt` + `durationMs`」，而 AGENTS.md 禁区写「**不擅自增删依赖**、改端口、改目录结构；需要时先在需求单登记并获批准」。阶段 1 未登记该依赖 → 实现期撞门禁，按铁律 7 停手出单。

## 可选方案

| 方案 | 做法 | 代价 | 影响面 | 是否改对外可见面/验收 |
|------|------|------|--------|----------------------|
| **A（建议）装 `python-multipart`** | 在 conda `learningguide` 里装该包，并把版本行追加进 `backend/requirements.txt`（与 r002 追加 livekit-api/aiohttp 的既有做法一致） | 新增 1 个纯 Python 小包（无 C 扩展）；需你批准装包 | 依赖清单 +1 行；接口形态、前端调用、验收条目**全不变** | **否** |
| B 不改依赖：上传改「原始 body + query 参数」 | 前端 `fetch(url, {body: blob, headers:{'Content-Type':'audio/webm'}})`，`segmentIndex/startedAt/durationMs` 走 query；后端用 `Request.body()` | 要改已批的接口形态与前端调用；multipart 的「一个请求带多个字段」优势消失（元数据进 URL，日志里会多出时间戳） | design §2.5 表格、前端 `api/transcripts.ts` 契约、用例写法 | **是**（对外可见面变 → 仍属 L3，需重写该条契约） |
| C 前后端都先不做上传 | 只落迁移/仓储/服务，上传能力留到下一轮 | 本轮 R1~R6 的核心（默认开启 + 并入对话）无法演示 | 需求单 E2/E3/E5 全部挂起 | 是（范围削减） |

## 建议
**A**。理由：① 设计已明确要 multipart（Whisper 官方与各家 REST 都是这个形态，后端调 STT 也用同一形态，前后端一致）；② `python-multipart` 是 FastAPI 官方文档指定的表单解析依赖（纯 Python、无编译）；③ 仓库对追加依赖有先例（r002 的 `backend/requirements.txt` 追加），流程上只需你一句批准；④ A 不改任何对外可见面，验收条目不用动。
