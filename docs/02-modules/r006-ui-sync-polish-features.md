## F-27 静音徽标（谁没开麦，一眼看到）

- **只有静音时才出现**一个小麦标（图标 + 悬停提示「麦克风已静音」）；开麦时不显示图标。
- 它与「有没有摄像头」无关：没开摄像头显示姓名首字头像块，开麦的人不会因此被标成静音。
- 自己和他人都一样：别人静音/取消静音，你的屏幕上**立刻**变化（实测秒级）。

## F-28 两端看到同一个数

- 状态条的「N / 容量 成员」是**名额**（在册成员），列表卡同口径；某一端批准/拒绝/踢人/移交/结束后，**其他端秒级跟上**（实测 0.23~0.46 秒），不需要刷新页面。
- 「此刻谁在线」仍在成员抽屉看（「在房间里 / 不在房间」）——名额与在场是两件事，别混。
- 房主/协管门牌上的「待批 N」也一样实时（实测 1.46 秒清空）；万一消息丢了，30 秒内也会自动对齐。

## F-29 侧边栏的个人信息（点击才展开）

- 左下角平时只有**头像 + 名字**；点一下（或用键盘 Tab 聚焦）才展开一个浮窗：名字、邮箱、加入日期、一句哲学语句、登出。
- `Esc` 或点击浮窗外面就收起；收起状态下看不到你的邮箱与账号 ID（要分享屏幕给别人看时更安心）。
- 里面那句是**每日一句**：同一天里打开几次都是同一句，第二天换新的。

## F-30 界面里的哲学语句

- 首页大图旁边、新建房间页、等待室、讨论与成员抽屉的空态、未登录时的侧边栏……这些「说明性文字」旁边会多一行小字，是一句哲学语录（附作者）。
- 原则：**只加不替** —— 所有功能性提示（比如「你将成为这个房间的房主」「还没有人发言」）原文保留，语句是额外的一行。
- 语录都是真实的（苏格拉底、庄子、加缪、罗素……）；同一位置的语句当天固定。

## F-31 首屏《思想者》的位置

- 图版初始（页面未滚动时）位置比之前**向下约 50px**（≈ 图版高度的 10%），滚动位移行为不变。
- 想再调：改 `styles/global.css` 里 `.hero` 的 `--thinker-top`（桌面 `-60px` / 窄屏 `-46px`）一个数即可。

## 不做

成员抽屉里不标麦克风状态；状态条不显示在场人数；语录不替换任何功能文案；不做「静音他人」这类服务端权限能力。
