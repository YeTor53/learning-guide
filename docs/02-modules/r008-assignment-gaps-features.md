## F-40 讨论纪要（房间结束后）

- 房间结束后回列表 → 切「已结束」→ 卡片上多了一个「**讨论纪要**」按钮。
- 房主/协管点「生成讨论纪要」→ 几秒后出现正文，分五节：**主题与背景 / 讨论要点 / 分歧与未决 / 待办与下一步 / 一句话总结**。
- 素材是这间房的真实记录（主题、成员、聊天与系统消息）；**材料不足时它会直说**「没有可归纳的内容」，不会编造观点或人名。
- 可以反复点「**重新生成**」——同一间房**只保留最新一份**，不会堆一堆版本。
- 普通成员可以查看，但不能生成（按钮位置会写明「纪要由房主或协管生成」）。
- 没配好模型密钥时，页面会直接告诉你「请在后端 `.env` 里填好 `LLM_API_KEY`」，而不是笼统报错。

## F-41 限时邀请（1 分钟）

- 房内右侧抽屉第三个 tab「**邀请**」（只有房主/协管能看到）。
- 选「30 秒 / 60 秒」+「1~5 次」→ 点「生成邀请码」→ 得到 6 位码 + 「复制链接」（形如 `/join?code=zqddjt`）。
- 列表里每条都显示「**还剩多少秒过期** · 已用几次」，过期或次数用尽会置灰标「已失效」。
- 对方打开链接 → 页面自动带好邀请码 → 点「加入房间」**直接进房**（不走等候室），房间里会留一条「XX 通过邀请链接加入」的记录。
- 房间满 8 人时凭码也进不来（会提示「房间已满」）；码过期/用错/次数用完都会明确告诉你原因。

## 不做

结束后不自动跑纪要（只做一键，避免外部失败污染结束流程）；不做纪要版本历史；邀请码不做长码/自定义密码。
