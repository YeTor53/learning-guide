## 1. 超管（管理员）能做什么

| 能力 | 表现 | 边界 |
| --- | --- | --- |
| 进任何**进行中**的房间（含满员） | 与普通成员同一入口；进房后控制坞显示「管理视角 · 隐身」 | 已结束房间仍是 409（历史内容只读）；不存在的房间 404 |
| 行使**任一房间房主**的管理动作 | 抽屉「成员」里可移出成员 / 设协管 / 移交房主 / 看门口待批申请；控制坞可「结束房间」 | 动作结果与房主完全一致，且**多留一条审计** |
| **隐身** | 不出现在成员列表与舞台；其他参与者根本看不到他；不计入房间人数 | 他自己界面能看到别人，也看得到自己不在成员列表 |
| **不发布音视频** | 控制坞没有麦克风 / 摄像头 / 共享屏幕 / 举手控件，只有一枚只读标识 | 即使手工改请求，服务端也会拒绝发布（Token 无发布权限） |
| 进**管理后台** | 侧边栏出现「管理后台」（**只有超管能看到这一项**） | 未登录会被引导去登录后回到后台；非超管打接口一律 403 |
| 大屏发言 | 右侧「大屏」面板里发言（所有人可见，含未登录访客） | 单条 ≤500 字；太频繁会被提示「发得太快了」 |

## 2. 管理后台（`/admin`）

四个分区（四张列表）：
1. **房间**：房间名 / 主题 · 房间码 / 房主 / 状态 / 在册 vs 容量 / 待批数 / 纪要状态 / 创建时间；动作：结束（进行中才有）、重生纪要、删除（行内二次确认）。
2. **用户**：显示名 / 邮箱 / 角色 / 最后活跃 / 在册房间数 / 房内发言数 / 大屏发言数；可「只看在线」。
3. **纪要**：房间 / 状态 / 模型 / 字数 / 更新时间。
4. **审计**：时间 / 操作人 / 动作（结束房间 · 删除房间 · 重生纪要）/ 对象 / 摘要。
- 搜索：房间按标题 / 房间码 / 房主名；用户按邮箱 / 显示名。分页每页 20 条，可翻页。
- **删除房间不可恢复**：会连带删掉该房的成员记录、聊天、转写与纪要；审计有一条流水（快照里保留房间标题与当时的统计），删后仍可追溯。
- 页面底部有一句常驻说明：「管理动作都会留痕……删除不可恢复」，避免误操作。

## 3. 全服大屏

- 入口：顶栏右侧「大屏」按钮 → 面板从**右侧**滑出（可 Esc 收起；记得上一次开/关状态）。**交流页不挂**这个面板（那里已有讨论/成员抽屉）。
- 谁能用：**未登录也能看**（只读），登录后可以发言；自己的消息靠右显示。
- 在线点：作者名后的小绿点 = 该用户最近有心跳（60 秒上报一次，判据窗口 120 秒）。
- 实时性：别人发言后，你的面板**不用刷新**就会出现（SSE 通知 + 30 秒轮询兜底；断线时不会丢消息，只可能晚一点）。

## 4. 权限矩阵（本轮新增部分）

| 动作 | 游客 | 成员 | 协管 | 房主 | 超管 |
| --- | --- | --- | --- | --- | --- |
| 看大屏 / 发大屏 | 看 ✔ / 发 ✘ | 看 ✔ / 发 ✔ | 同成员 | 同成员 | 同成员 |
| 进房间（满员时） | ✘ | 已在房 | — | — | ✔ |
| 看门口待批申请 | ✘ | ✘ | ✔ | ✔ | ✔ |
| 移出成员 / 设协管 / 移交房主 | ✘ | ✘ | 部分（协管不能动协管） | ✔ | ✔（任意房） |
| 结束房间 | ✘ | ✘ | ✘ | ✔ | ✔（任意房） |
| 打开管理后台 / 调后台接口 | ✘ | ✘（403） | ✘（403） | ✘（403） | ✔ |
| 出现在成员列表 / 舞台 | — | ✔ | ✔ | ✔ | **✘（隐身）** |
