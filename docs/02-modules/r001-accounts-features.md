### F-A-01 注册账号

- **入口**：导航栏「注册」按钮 → `/register`；或 F-A-05 的引导跳转。
- **前置拦截（按判断顺序，命中即停）**：① 邮箱为空 → 提示「请输入邮箱」；② 邮箱格式不合法 → 「邮箱格式不正确」；③ 显示名为空 → 「请输入显示名」；④ 显示名超过 32 字 → 「显示名最多 32 个字」；⑤ 密码少于 8 位 → 「密码至少 8 位」；⑥ 提交后服务端返回 `EMAIL_TAKEN` → 「该邮箱已注册，直接登录或换一个」；⑦ 其他错误 → 「注册失败：{原因摘要}」。
- **界面元素**：页标题「注册」；三个输入框（邮箱 / 显示名 / 密码，密码为密码型输入）；主按钮「注册」；次要链接「已有账号？去登录」；表单下方错误条（红色，展示当前一条错误）。
- **流程**：填表 → 前端校验 → 提交（按钮进入「注册中…」并禁用）→ 成功：写入会话并跳转（有 `returnTo` 则回该页，否则回房间列表）。
- **四种状态**：加载＝按钮「注册中…」、输入禁用；空态＝三个框皆空、主按钮可点但点了只提示；失败＝错误条显示原因、输入保留、按钮恢复；成功＝跳转目标页，导航栏显示显示名与「登出」。
- **规则**：注册成功即登录（不要求再登录一次）；邮箱大小写不敏感且唯一（服务端为准，前端只做格式检查）。
- **验收点**：新邮箱注册后直接落回目标页且导航栏显示显示名；同一邮箱换大小写再注册 → 页面显示「该邮箱已注册，直接登录或换一个」。

### F-A-02 登录

- **入口**：导航栏「登录」→ `/login`；F-A-05 引导。
- **前置拦截（按顺序，命中即停）**：① 邮箱为空 → 「请输入邮箱」；② 密码为空 → 「请输入密码」；③ 提交后 `INVALID_CREDENTIALS` → 「邮箱或密码不正确」（不区分是哪个错）；④ 其他错误 → 「登录失败：{原因摘要}」。
- **界面元素**：页标题「登录」；邮箱 / 密码输入框；主按钮「登录」；次要链接「还没有账号？去注册」；错误条。
- **四种状态**：加载＝「登录中…」+ 输入禁用；空态＝两框皆空；失败＝错误条 + 输入保留（密码清空）；成功＝跳转（有 `returnTo` 回该页，否则房间列表）。
- **验收点**：用种子账号 `host@example.com` / `demo1234` 能登录；密码错与邮箱不存在显示同一条文案。

### F-A-03 登出

- **入口**：导航栏「登出」（仅已登录可见）。
- **行为**：点击即执行，不弹确认；服务端清会话 Cookie → 回到房间列表页；导航栏恢复「登录 / 注册」。
- **失败**：接口失败时提示「登出失败，请重试」，**不清本地状态**（避免"看起来登出了其实没登出"）。
- **验收点**：登出后刷新页面仍是未登录；直接访问需登录页面被引导到登录页。

### F-A-04 首屏会话恢复

- **行为**：任何页面首次加载都请求一次当前用户；未登录返回空、界面按未登录渲染；已登录则**侧边栏个人信息区**显示头像首字母、显示名、用户 id、邮箱、注册时间与「登出」。
- **四种状态**：加载＝侧边栏该区显示「加载中…」（不闪烁「登录/注册」）；空态＝显示登录 / 注册按钮与一句说明；失败＝按未登录渲染并静默；成功＝显示个人信息。
- **验收点**：登录后刷新任意页面，导航栏不闪"登录/注册"。

### F-A-05 未登录引导

- **触发**：未登录时点「创建房间」「申请加入」「离开房间」「结束房间」等需登录动作。
- **行为**：跳转 `/login?returnTo=<当前页>`；登录或注册成功后回到 `returnTo`。`returnTo` 必须是站内相对路径，外部/协议地址一律忽略（回房间列表）。
- **验收点**：未登录点「创建房间」→ 登录页 → 登录成功 → 回到建房页，而不是首页。

### F-A-06 表单校验与错误呈现

- 前端校验只为「少一次往返」，**服务端校验为准**：前端放过的非法值，服务端返回 `VALIDATION`/`EMAIL_TAKEN` 时同样按 §3 文案呈现。
- 错误只显示一条（最新的那条），避免一屏红字；输入框失焦即校验该字段，提交时校验全部。

## 3. 界面区块顺序

1. 顶栏（折叠开关 + 站名 + 当前区块面包屑）与**左侧边栏**（导航：返回主页 / 我的房间 / 创建房间；个人信息区；登出 / 收起）——AD-0007
2. 表单卡片标题
3. 表单字段（自上而下：邮箱 → 显示名（仅注册）→ 密码）
4. 错误条（无错误时不占位）
5. 主按钮
6. 次要链接（去注册 / 去登录）

## 4. 按钮矩阵（登录态 × 动作）

| 动作 | 未登录 | 已登录 |
| --- | --- | --- |
| 侧边栏底部 | 「登录」「注册」（在个人信息区） | 「登出」 |
| 注册页主按钮 | 「注册」 | 不可达（已登录访问 `/register` 直接回房间列表） |
| 登录页主按钮 | 「登录」 | 不可达（同上） |
| 创建房间 / 申请加入 | 触发 F-A-05 引导 | 正常执行 |

## 6. 端到端演示脚本（单浏览器即可，约 90 秒）

1. 打开首页 → 导航栏显示「登录」「注册」。
2. 点「注册」→ 填入新邮箱 `demo1@example.com` / 显示名「演示一号」/ 密码 `demo1234` → 点「注册」。
3. 观察：直接回到房间列表，导航栏显示「你好，演示一号」与「登出」。
4. 点「创建房间」→ 能进建房页（说明注册即登录生效）。
5. 点「登出」→ 导航栏回到「登录」「注册」。
6. 未登录状态下点「创建房间」→ 跳到登录页（带 `returnTo`）。
7. 用 `host@example.com` / `demo1234` 登录 → 自动回到建房页。
8. 故意把密码输错一次 → 页面显示「邮箱或密码不正确」，输入框仍保留邮箱。
