## 3. 阅读顺序建议

1. 想快速了解「现在能做什么」→ 最新一轮的**功能页**（r002 → r004 接续）。
2. 想知道「代码怎么组织的」→ 最新一轮的**实现页** + `01-architecture/` 的对应增量页。
3. 想改某个能力 → 先读该能力**最早定义它的轮次页**（约束从那里来），再读最新页（现状）。
