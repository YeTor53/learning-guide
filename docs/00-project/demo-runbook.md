配套事实源：`README.md`「两个浏览器演示完整路径」、`docs/tutorials/r002-livekit-demo.md`、`r004-room-extras-demo.md`、`r010-transcription-user-guide.md`、`r011-invite-entry-and-capacity.md`、`r012-admin-and-global-chat.md`（r012 专项）。
窗口约定：**A = 房主**（普通窗口）、**B = 参与者**（无痕窗口）、**C = 邀请码客人**（第二个无痕窗口）、**D = 超管**（普通窗口，登 `admin@example.com`）、**W = 转写进程窗口**（`agents.bat` 那个黑窗口）。
r012 三段（S10/S11）只需 A、D 两个窗口；若上一轮已把 A 用完，S10 起直接用 D 即可，A 只用来当「看不到超管」的对照组。

## 0. 演示前 30 分钟（照单打勾，顺序别换）

| # | 在哪 | 动作 | 看到什么才算好 |
| --- | --- | --- | --- |
| 1 | 仓库根双击 | `agents.bat`（真识别，消耗免费档）或零配额：先开 `cmd`，`set AGENT_STT=fake` 回车，再 `agents.bat` | 窗口里出现 `registered worker`；**这个窗口全程别关**（它挂了芯片会变「未开启」） |
| 2 | 仓库根双击 | `dev.bat` | 打印后端 `127.0.0.1:8000`、前端 `localhost:5173`；要自检用 `dev.bat check` |
| 3 | 任意终端 | `python backend/scripts/db_init.py --reset --seed` | 输出 `schema_migrations 12`、**4 个演示账号（含超管）**、示例房间 |
| 4 | 浏览器 A | 用 `host@example.com / demo1234` 登录 → **随建一个房 → 进 → 退出**（预热） | 首次连 LiveKit 偶发换区，实测最慢 **24.2 秒**；预热后别人进房 0~2 秒 |
| 5 | 浏览器 B、C | 均为**无痕**窗口，别登录 | 三窗口**并排**，缩放 100% |

## 3. 逐步脚本（每步：在哪 → 点什么 → 看什么 → 话术 → 兜底）

### S1 开场（0:00–0:20）
- **在哪**：A 窗口停在首页（`localhost:5173`），不点。
- **看什么**：首屏标题「学习讨论室」、下方房间列表与主题筛选。
- **话术**：「这是围绕一门学习主题的多人音视频讨论室：账户、房间、等候室、三种角色权限、群聊、举手、焦点发言、屏幕共享、服务端踢人、会后 LLM 纪要，外加语音实时转写。」
- **兜底**：列表空 → `db_init --reset --seed` 后按 F5。

### S2 登录 + 建房（0:20–0:55）
1. **A 窗口**：顶栏**右上角**点「**登录**」→ 邮箱填 `host@example.com`、口令 `demo1234` → 点表单里的「**登录**」（按钮在表单底部，提交中显示「登录中…」）。
   - 看不到演示账号提示？登录页左侧有小字「演示账号 host@example.com / demo1234」。
2. **A 窗口**：顶栏**最左**的方框图标点一下**展开左侧栏**（默认收起）→ 点「**创建房间**」。
3. 建房页：标题「创建一个学习讨论室」。
   - 「**主题**」：从卡片组里点一张，例如「**西方哲学史**」（14 个预设，含题目点名的哲学 / 数理生物学 / 德国史）。
   - 「**标题**」：输入「第一次读书会」（随便，建议自带房名好认）。
   - 「**简介**」：可留空（或一句「演示用」）。
   - 点底部「**创建房间**」（提交中「创建中…」）。
- **看什么**：**直接跳进交流页**（不再有中间「房间管理页」）；底部悬浮控制坞出现；状态条左侧显示「**1 / 8 成员**」（在册口径）。
- **话术**：「主题是房间的绑定属性；角色三种：房主、协管、成员。建房后我把房主的二维码（房间码）留在抽屉里，后面用。」
- **兜底**：建房偶尔慢一两秒是后端在建 LiveKit 房间并派转写 worker（不影响）。

### S3 申请 → 等候室 → 批准（0:55–1:25）
1. **B 窗口**（无痕）：`localhost:5173` → 登录 `part@example.com / demo1234` → 首页找到刚才那间房（标题「第一次读书会」）→ 点卡片上的「**申请加入**」（可留一句话）。
2. **B 窗口**：页面**自动落到等待室**：三步时间线（已提交 → 等待房主批准 → 进入房间）+ 安抚语录；按钮有「**撤回申请**」和「**回房间列表**」。
3. **A 窗口**：状态条**右侧**点「**讨论与成员**」打开抽屉 → 顶部切到「**成员**」tab（tab 上有红色待批数字）→ 待批那一行点「**批准**」。
- **看什么**：**B 端不点任何东西**，最坏 2 秒轮询 + 1.5 秒跳转 ≈ **3.5 秒**自动进交流页；A 端状态条变成「**2 / 8 成员**」，讨论流出现「XX 加入了房间」。
- **话术**：「房间不可直进，必须过等候室；容量按**本房在册成员**算（ADR-0016），满了申请和批准都会被挡。」
- **兜底**：B 端一直停在门口 → 检查 A 点的是不是「批准」（别点成「拒绝」）；A 端抽屉里若没有待批行 → 按 F5（编号徽标 3 秒内也会自己更新）。

### S4 群聊 + 举手 + 给焦点 + 说话不夺焦点（1:25–2:25）
1. **B 窗口**：点「**讨论与成员**」→「**讨论**」tab → 底部输入框（占位文字「回车发送 · Shift+回车换行」）输入「今天我们先讲第一章」→ 按 **Enter**（或点右侧「**发送**」）。再发一条。
   - **看什么**：A 窗口抽屉「讨论」里**秒级**出现同两条消息（广播加速 + HTTP 落库）。
2. **B 窗口**：底部控制坞点「**举手**」（参与者身份文案），按钮变「放下手」，B 自己格子上出现描边/闪烁。
   - **A 窗口**：状态条右侧「讨论与成员」徽标出现提示；抽屉「成员」里 B 那行显示 ✋。
3. **A 窗口**：切「**成员**」tab → B 那一行点「**给焦点**」（按钮变「取消焦点」）。
   - **看什么**：两端舞台主区都切到 B（**1.4 倍份量**放大，实测 3 人档 556×631 vs 396×631）；底部出现「某某正在发言」；B 端控制坞文案变「**退出焦点**」。
   - 也可在舞台格子上直接点 B 格子上的「**给焦点**」角标（举手格才会显示）。
4. **B 窗口**：连续说话 **10 秒**（不要举手）。
   - **看什么**：**舞台主区不切换**，只在 B 格子上出现声波/「正在发言」高亮。
   - **话术**：「焦点只有两个来源：**举手→管理给焦点**，或房主/协管直接指定。我们做过自动焦点，噪声一多画面就抽播，所以**说话不再获得焦点**。」
5. **B 窗口**：点控制坞「**退出焦点**」（或 A 在成员行点「取消焦点」）→ 主区恢复均分铺满。
- **兜底**：A 端成员行没有「给焦点」按钮 → A 必须是房主/协管，且 B 在册；两端不同步 → 等 3 秒兜底轮询；仍不同步按 F5（现在切回窗口会自动刷新）。

### S5 屏幕共享与优先级（2:25–2:55）
1. **B 窗口**：控制坞点「**共享屏幕**」→ 浏览器弹窗里选**「整个屏幕」或窗口**（别选单个标签页）→ 点「共享」。
   - **看什么**：B 的按钮变「停止共享」；两端共享画面**顶掉焦点格**占主区，其余人缩到底部人像条。
2. **A 窗口**：说一句话（或让 B 说）。
   - **看什么**：**主区仍是共享画面**，不被说话抢走。
3. **B 窗口**：点「**停止共享**」。
   - **看什么**：主区恢复宫格/焦点（纯派生，不需要任何确认）。
- **话术**：「优先级写死在 ADR-0014：共享 > 手动焦点 > 自己。共享是要一起看的内容，不能被说话抢走。」
- **兜底**：共享失败 → 换窗口源重试；A 端若想帮他停，可在抽屉「成员」里该行点「**请求停止共享**」（协作式，对方客户端自己停）。

### S6 语音转写（2:55–3:45）
1. **确认 W 窗口**（`agents.bat`）还在跑；**若刚才没起**，现在起也行，但**必须随后新建一个房**（派单只发生在建房那一刻）。
2. **A 窗口**：回首页 → 左侧栏「**创建房间**」→ 再建一间「**转写演示**」→ 进交流页。
   - **看什么（1）**：进房顶部一条告知条「本房间会把说的话转成文字……关掉麦克风即不参与转写」→ 点「**知道了**」收起。
   - **看什么（2）**：底部控制坞右侧芯片，先显示「**转写：未开启**」，约 **13 秒**内自己变成「**转写：开启**」（此前显示未开启是正常的）。
3. **A 窗口**：控制坞点「**麦克风**」（或按 **M**）确保开着，说一句中文：「**今天我们先讲第一章线性回归**」。
   - **看什么**：抽屉「讨论」里先出现淡色「识别中…」，随后**定稿成气泡**（带说话人、时长、左侧色条）。
4. **B 窗口**：若 B 也在房里并开麦，说一句，看到了同一条流（转写是**房间级**的）。
- **话术**：「识别在**房间侧**完成（LiveKit Agents + 官方 Inference）；我们只把最终文字落库并并入同一条讨论流，不存音频、只存文字。」
- **兜底**：芯片一直「未开启」→ ① 看 W 窗口是否还在（脚本带 3 秒自动重启）② 房间是**先建后起 worker** 的话补派单：`python backend/scripts/dispatch_agent.py <room_id>` ③ 把鼠标停到芯片上，提示里会写「最后心跳 X 秒前」。**不想花额度**：用 `set AGENT_STT=fake && agents.bat`（气泡是桩文本，链路一致）。

### S7 限时邀请码：两条路径（3:45–4:25）
**路径一（复制链接，主推）**
1. **A 窗口**：抽屉 →「**邀请**」tab（仅房主/协管可见）→「有效期」选 **30 秒**、「可用次数」选 **1** → 点「**生成邀请码**」。
2. **A 窗口**：码行右侧点「**复制链接**」（按钮变「已复制」；行内显示「**N 秒后过期 · 已用 0/1**」倒计时）。
3. **C 窗口**（无痕，未登录）：地址栏粘贴链接（形如 `http://localhost:5173/join?code=zqddjt`）→ 回车 → 页面标题「输入邀请码」，输入框**已预填**该码。
4. **C 窗口**：若未登录，点「**去登录并加入**」→ 用 `part@example.com` 或新注册一个 → 登录成功后**自动回到该页并自动加入**（不用再点一次）；已登录则直接点「**加入房间**」。
   - **看什么**：C **直接进交流页**（跳过等候室，在册 +1）；A 端讨论流出现「XX 通过邀请链接加入」，状态条人数变 3 / 8。
**路径二（只有码，手输）**
5. **C 窗口**（或再开一个无痕）：打开 `localhost:5173` → 顶栏最左方框图标**展开左侧栏** → 点「**邀请码加入**」→ 输入框填 6 位码 → 点「**加入房间**」。
   - 未登录同样会引导登录并自动闭环。
- **话术**：「作业必做要『限时邀请链接或房间码 + 过期时间』：6 位码、**最长 60 秒**、默认 1 次、满员仍按容量挡。顶栏入口是补的 —— 否则只有『拿到链接的人』能进，手上有码的人没处输。」
- **兜底**：提示过期/已用尽 → 当场重新生成（选 60 秒 + 3 次更保险）；复制失败 → 走上一步手输码。

### S8 移出成员 + 结束房间（4:25–4:45）
1. **A 窗口**：抽屉「**成员**」tab → 在 C（或 B）那一行点「**移出**」→ 弹确认「确认移出该成员？移出后对方会立刻断开。」→ 点确认。
   - **看什么**：对方那端**立即**断线并显示「你已被移出房间」，刷新也回不来；A 端顶部提示「已移出该成员」。
   - **话术**：「踢人走**服务端** LiveKit Room Service 真断开，不是前端假踢；外部调用失败也不回滚业务真相（接口会如实返回 `livekitApplied=false`）。」
2. **A 窗口**：控制坞最右点「**结束房间**」（危险色）→ 确认框里点结束。
   - **看什么**：所有端显示「房间已结束」，房间转**只读**；成员状态变「房间结束 / 主动离开」。
- **兜底**：被移出的人可重新申请（作业口径允许，不必慌）。

### S9 讨论纪要（4:45–5:15）
1. **A 窗口**：顶栏品牌「学习讨论室」点回首页（或左侧栏「返回主页」）→ 房间列表上方状态切到「**已结束**」。
2. **A 窗口**：找到「第一次读书会」卡片 → 点卡片上「**讨论纪要**」→ 进纪要页 → 点「**生成讨论纪要**」。
   - **看什么**：转圈几秒（实测 **6.0 秒 / 632 字**）→ 出现 Markdown：主题与背景 / 讨论要点 / 分歧与未决 / 待办 / 一句话总结；按钮变「**重新生成**」（覆盖同一份）。
3. **讲点**：素材 = 聊天 + 成员 + 主题 + **语音转写**（可指着某句转写说「它也进来了」）。
- **话术**：「纪要走服务端唯一 LLM 出口，提示词里明确禁止编造；失败会留痕并如实提示，不假装成功。」
- **兜底**：提示未配置模型 → `.env` 的 `LLM_API_KEY` 为空（对照 `docs/00-project/ai-tools-and-models.md`）；额度/网络问题 → 直接读已生成那份，别临场排查。

### S10 管理后台（5:15–5:45，r012 / 加分项④）

1. **D 窗口**（超管）：`localhost:5173` → 顶栏右上「**登录**」→ `admin@example.com / demo1234`。
   - **看什么**：左侧栏比普通账号**多一项「管理后台」**（普通账号看不到，这是设计）。
2. **D 窗口**：点「**管理后台**」→ 后台页（大标题「管理后台」，副标题「共 N 条」）。
   - 右侧搜索框（占位「搜房间标题 / 房间码 / 房主」）输入刚才那间房的名字（如「第一次读书会」或「转写演示」）→ 该行被筛出来。
3. **D 窗口**：该行点「**纪要**」→ 右上出现「正在生成纪要，请稍候…」→ 变成「**纪要已生成**」。
   - **讲点**：同一份纪要，**超管也能重生**——他行使的是房主同一条业务（`POST /api/rooms/{id}/summary` 复用），不是另开一条旁路。
4. **D 窗口**：顶部切到「**审计**」→ 看到刚才那条「**重生纪要**」留痕（列：时间 / 操作人 / 动作 / 对象 / 摘要）。
   - **话术**：「管理后台三件事：**结束、删除、重生纪要**——每个动作都会写一条审计流水（`admin_audit`），所以有动作必有痕迹；「删除」是**硬删**（连带成员记录、聊天、转写、纪要一起清），行内要做二次确认，我在台上**不点它**——想看的话审计里照样留快照（删前房间标题与统计）。」
5. （可选 8 秒）**D 窗口**：切「**用户**」→ 点「**只看在线**」→ 列表只剩最近有心跳的人，「最后活跃」列就是心跳时间。
- **兜底**：进后台只看到一句「只有管理员能进这里」→ 当前登录的**不是超管**（切 `admin@example.com`）；后台打不开 → 直接讲审计与四列表的设计，别临场查库。

### S11 超管隐身 + 全服大屏（5:45–6:15，r012）

1. **A 窗口**（房主）：打开那间**还在进行中**的房（S6 建的「转写演示」）→ 抽屉「**成员**」记下现在的在册（例如「2 / 8 成员」）。
2. **D 窗口**（超管）：地址栏直接进**同一间房** `/rooms/<房间id>/live`（他**不是**这间房的成员）→ 进得去。
   - **看什么**：顶部一条提示「**管理视角：你以隐身方式在场（不出现在成员列表与舞台、不计入人数），不发布音视频，只做管理。**」；底部控制坞最左是**只读标识**「**管理视角 · 隐身**」，右侧只有「**离开**」「**结束房间**」，**没有**麦克风 / 摄像头 / 共享屏幕 / 举手。
3. **A 窗口（关键那一眼）**：按一下 **F5**（或等它自动刷新）→ 成员列表**没有**「平台管理员」、舞台**没有**他的格子、状态条人数**没变**。
   - **话术**：「隐身是两层：他自己界面只留一枚只读标识；对别人来说他**不进成员表**（所以列表 / 舞台 / 人数天然不含他），而且在 LiveKit 侧他的 Token 带 `hidden`、**禁止发布**——服务端参与者列表里他是 `hidden=true / canPublish=false`，绕过前端也发不出音视频、也看不见他。」
4. **A 窗口**：两条路都能发——①（r013 起）就在交流页：状态条右侧「讨论与成员」→ 切第 4 个 tab「**大屏**」；② 回「**房间列表**」点顶栏「**大屏**」从右滑出。输入「**管理员巡场：今晚 8 点开始**」→ 点「**发布**」（或回车）。
5. **D 窗口**：也回**首页** → 顶栏点「**大屏**」→ **不用刷新**，几秒内出现刚才那条；**C 窗口（未登录的无痕窗口）**同样能看到。
   - **话术**：「大屏是**全服**公开面：未登录只能看、登录才能说；实测靠 SSE 推送**秒级**到达，断线还有 30 秒轮询兜底，所以列表页刷新慢一点也不会丢。」
6. **D 窗口**：面板右上 × 或 **Esc** 收起。
- **兜底**：A 端竟然看到超管 → 当场按 F5 复看一次，仍出现就说「这条我记下来，回去查 grants 与成员表」（别硬讲）；大屏不出现 → 看面板标题「N 人在线」与输入框在不在，在就口播「SSE 最长晚 30 秒」；**别在台上点「删除房间」**。

### S12 收尾：作业对照与取舍（6:15–6:35）
- **操作**：回首页（大屏面板记得收起）；可切到 `docs/00-project/assignment-a-coverage.md` 讲。
- **话术**：「必做 15/15 完成；加分项：**简单管理后台已完成**（就是刚才 S10，房间 / 用户 / 纪要 / 审计 + 三动作留痕）、**演示录屏**就是本台本第 5 节、转写已完成、**录制经权衡不做**、断线重连**部分**（人工演练待做）、Docker 一键启动与公网部署排在 r012 之后。数据层 **12 个迁移**、冒烟 **59 步**、pytest **202 项**、真机交叉验证脚本 **17 条判据**、台本 UI 自检脚本一份。」
- **兜底**：被追问取舍 → 翻 `docs/rounds/*/review.md` 的「未闭合项」（r012 那份在 §6），那里逐条写了为什么没做。

## 3.5 现场加演（可选）：点一下，让一个固定演示账号真被断一次

**首选**（观感最好，需管理员）：`demo-firewall-cut.bat` —— 点一下，临时防火墙掐断本机到 LiveKit 的出网 12 秒，然后自动删规则。

### 首选：`demo-firewall-cut.bat`（2026-09-20 干净基线实测）
- **前提**：两个窗口都必须是「已连接」（先让两端连好再点；实测若某端已经是「正在重连…」，它可能走到「已断开」且不自己回来）。首次连接顺序：房主窗口先连，参与者约 6 秒后连上。
- 双击 `demo-firewall-cut.bat`（默认 12 秒；也可 `demo-firewall-cut.bat 10`；`--status` 只看状态；`--remove` 手清残留）。不是管理员会自动弹 UAC。
- **台下能看到**：断的过程中**两端都在正常渲染**，房主端约 **1 秒**、参与者端约 **3 秒**显示「正在重连…」（控制坞变灰）；
- **恢复**：12 秒后规则自动删除，两端约 **5~6 秒**自己回到「已连接」，**不用点任何按钮**，举手保持、地址栏没跳走。
- **代价**：这是整机级阻断（本机所有经 LiveKit 的连接都会断，也就是台上两个窗口同时演）；规则名 `lg-demo-cut`，脚本 `try/finally` 保证删掉，万一被强杀用 `--remove` 清。

1. 演示前：`demo-window.bat part` 开一个受控窗口（固定 profile，第一次登录 `mod@example.com`），把它当**窗口 B**（被断的那个）。其它窗口照旧。
2. 加演时（房主在另一窗口面对面看着）：双击 `demo-firewall-cut.bat`（默认 12 秒）。
3. **台下看什么（2026-09-20 实测口径，别多讲）**：
   - 断的过程中：被断窗口画面**停在断前那一帧**（还写「已连接」）→ 引导看**另一端**：成员列表里那位变「不在房间」（实测断后约 2~3 秒生效）；
   - 恢复后约 1~2 秒：被断窗口出现「正在重连…」，控制坞变灰；
   - 再约 2~4 秒：自己回到「已连接」，地址栏没跳走、页面没白屏，**举手/焦点保持**。
4. **兜底**：若 8 秒后仍停在「已断开」→ 点「房间列表 → 回到讨论」重进（实测出现过一次，别赌）。
5. 为什么不做成「断的过程中这一端就显示正在重连…」：那需要网络层真阻断（临时防火墙规则 / 关 Wi-Fi），要动系统设置；方案与三种手段对比见 `docs/00-requirements/r013-demo-readiness.md` §10.5。

## 4. 故障兜底表（台上 10 秒自救）

| 症状 | 最可能原因 | 处置 |
| --- | --- | --- |
| 芯片「转写：未开启」 | worker 不在场 / 房间先建后起 worker | 看 W 窗口 → `dispatch_agent.py <room_id>` 补派 → 等 15 秒 |
| 邀请码提示过期 | 60 秒上限到了 | 当场重新生成（60 秒 + 3 次） |
| 满员被拒 / 待批被自动拒 | 在册 = 8 | 让一人点「离开房间」再申请 |
| 纪要点不动或报错 | LLM key / 额度 / 网络 | 讲已生成那份，并说明「失败留痕」设计 |
| 某端没声音 | 该端没开麦或设备选错 | 控制坞切设备；或让另一人继续 |
| 进房卡 20 多秒 | 首次连 LiveKit 换区（实测最慢 24.2 秒） | 口播「首次在建区，之后 0~2 秒」，别停手 |
| 系统消息（XX 加入了房间 / 通过邀请链接加入 / 被移出房间）没马上出现 | 广播补发（cp-8c）要等到本端下一次拉取 | 3 秒内会到；仍没有按 F5 —— 库是真相 |
| 页面像停在旧状态 | —— | 切回窗口现在会**自动刷新**；仍不对按 F5 |
| 找不到抽屉 | —— | 状态条**右侧**「讨论与成员」；Esc 收起 |
| 交流页找不到「大屏」按钮 | 交流页的入口在右抽屉里（顶栏不显示该按钮） | 「讨论与成员」→ 切「大屏」tab（第 4 个）；常规页仍可点顶栏「大屏」 |
| 后台只有一句「只有管理员能进这里」 | 当前不是超管 | 换 `admin@example.com / demo1234` 登录 |
| A 端看到了「平台管理员」 | 超管隐身没生效（应当不会发生） | 按 F5 复看一次；仍出现就如实记下、别硬讲（这是 r012 的验收项之一） |
| 大屏发了对方不出现 | SSE 断线（最多晚 30 秒）或对方没打开面板 | 等 10 秒；仍不出现说明「HTTP 是真相、通知丢了不影响数据」 |
