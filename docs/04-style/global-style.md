## 1. 代码与文档约定

- 命名：文件 `rNNN-*`（单轮）/ `global-*`（跨轮）；函数 `snake_case`（Python）、`camelCase`（TS）。
- 提交：`type(scope): ≤50字 [Req: rNNN]`；`git add` 只写具体路径；历史 append-only（禁 amend / rebase -i / squash）。
- 文档：一个概念只在一处讲，别处链接；仓库文档只写本项目方案与决策，不夹带外部出处。
- 界面文案一律中文，用「你」称呼用户；错误提示给「发生了什么 + 能做什么」。

## 2. 视觉基调

- 基调：**暗色编辑风**（ink 底色 + 高对比正文 + 单一强调色），细网格与噪点作为质感层，避免纯黑纯白的死板对比。
- 版式优先：标题用大字号显示体 + 紧字距；点缀可用衬线斜体（`Songti SC` / `Georgia`）制造编辑感；正文行高 1.7，测量宽度不超过约 72 字符。
- 动效原则：**克制而有物理感**——位移短（≤12px）、缓动统一、只对「状态变化」动，不对装饰反复动。

## 3. 设计令牌（实现于 `frontend/src/styles/global.css` 的 CSS 变量）

| 类别 | 令牌 | 取值 | 用途 |
| --- | --- | --- | --- |
| 底色 | `--ink-900 / --ink-800 / --ink-700` | `#08090c` / `#0d0f14` / `#141821` | 页面底、卡片、悬浮层 |
| 文本 | `--text / --text-dim / --text-mute` | `#eef1f6` / `#a8b0c0` / `#6b7385` | 正文、次要、占位 |
| 强调 | `--accent / --accent-soft` | `#7cf0c4` / `rgba(124,240,196,.14)` | 主按钮、焦点、状态 |
| 语义 | `--warn / --danger / --ok` | `#ffb86b` / `#ff6b6b` / `#7cf0c4` | 提示、破坏性操作、成功 |
| 描边 | `--line / --line-soft` | `rgba(255,255,255,.10)` / `.06` | 分隔线、卡片边 |
| 圆角 | `--r-sm / --r-md / --r-lg` | `6px` / `12px` / `20px` | 控件、卡片、区块 |
| 间距 | `--s-1 … --s-6` | `4 / 8 / 12 / 16 / 24 / 40px` | 统一节奏，禁止随手写数值 |
| 动效 | `--t-fast / --t-base / --t-slow` | `120ms` / `240ms` / `420ms` | 悬停、状态切换、入场 |
| 缓动 | `--ease` | `cubic-bezier(.2,.8,.2,1)` | 全站统一 |

## 4. 排版阶梯

| 角色 | 字号 / 字重 | 说明 |
| --- | --- | --- |

| H1 | `clamp(28px, 4vw, 44px)` / 700 | 房间标题 |

## 5. 图标规范

- 唯一来源：`lucide-react`；尺寸 `16 / 18 / 20`，`strokeWidth 1.75`，与文字基线对齐（`vertical-align: -2px`）。
- **界面中禁止 emoji**（含状态、空态、提示、按钮）；状态用「图标 + 文字」表达（例：`<Check/> 已批准`）。
- 图标只做语义补充，不单独承担含义：任何图标旁必须有文字或 `title/aria-label`。

## 6. 动效清单（允许的动效，全部可降级）

| 场景 | 效果 | 令牌 |
| --- | --- | --- |
| 首屏 hero | 标题逐字上浮淡入（阶梯 `--i`） | `--t-slow` + `--ease` |
| 卡片悬停 | 指针跟随聚光 + 轻微倾斜（≤2°）+ 边框提亮 | `--t-base` |
| 列表 | 阶梯入场（`--i` 步进 40ms） | `--t-base` |
| 按钮 | 按下 0.98 缩放；主按钮悬停亮度提升 | `--t-fast` |
| 路由切换 | View Transitions API（能力探测）；不支持时直接切换 | `--t-base` |
| 加载 | 骨架屏微光扫过（不用跳动动画） | 2s 循环 |
| 背景 | Canvas 流场（hero 区域），页面不可见时暂停 | rAF |

**降级底线**：`prefers-reduced-motion: reduce` 时关闭位移、倾斜、流场与逐字动画，只保留淡入与状态变色。

## 7. 导航与入口规范（ADR-0007 / ADR-0009）

| 元素 | 位置与形态 | 说明 |
| --- | --- | --- |
| 登录 / 注册 | **顶栏右上角**，无边框文字链接（`.link-plain`，悬停变强调色） | 全局入口，不用按钮样式，不占侧边栏信息位 |
| 已登录标识 | 顶栏右上角显示名（点击进「我的房间」） | 点击即跳转，不做下拉菜单 |
| 主导航 | 侧边栏上半区（返回主页 / 我的房间 / 创建房间） | 当前项用强调色胶囊 + 左侧竖条；可折叠为图标条 |
| 个人信息 | **侧边栏左下角** | 头像首字母 + 显示名 + 用户 id + 邮箱 + 注册时间；登出紧随其后 |
| 未登录态 | 侧边栏左下显示「未登录 / 右上角登录后可见」占位 | 不把登录 / 注册按钮放进侧边栏 |

## 8. 错误呈现规范

任何失败都必须让用户知道**发生了什么、下一步点哪里**；禁止一句话兜底：

| 类别 | 判定 | 必须包含 |
| --- | --- | --- |
| 未登录 | `ApiError.status === 401` | 「请先登录」+ 该功能为何需要登录 +「去登录」（带 `returnTo`）+ 可选「取消/看全部」 |
| 业务错误 | 其它 4xx（`NOT_FOUND` / `ROOM_FULL` / `ROOM_ENDED` / `CONFLICT` …） | 原样展示服务端 `message` + 可恢复动作按钮（重试 / 返回列表） |
| 连不上后端 | 网络异常 / 5xx | 「连不上后端」+ 错误摘要 +「重试」；不要提示「房间不存在」这类业务猜测 |

- 加载态用骨架屏，不用转圈；空态用图标 + 一句说明 + 一个主行动。
- 同一页面同时只展示一条错误（最新的那条）。

## 9. 可达性与交互底线

- 焦点可见：`:focus-visible` 显示 2px 强调色描边，禁止 `outline: none`。
- 颜色对比：正文与底色对比度 ≥ 7:1；次要文本 ≥ 4.5:1。
- 触控目标 ≥ 36px；侧边栏折叠只隐藏文字，不隐藏可点区域。
- 不做自定义鼠标指针、不隐藏滚动条、不自动播放声音。
- 表单：`label` 与控件显式关联；错误提示用 `role="alert"`。

## 10. 界面文案规范

- **不出现内部工程词汇**：界面（以及 README 的产品叙述）不写「题目 / 考核 / 作业 / 轮次 / 里程碑 / 检查点 / ADR 编号 / cp-rNNN / M1–M5」这类只对内部有意义的东西；这些只存在于 `docs/` 与提交信息里。
- 语言：中文，称呼用户用「你」；不用营销腔，也不自嘲（「简陋」「临时」这类字眼同样掉价）。
- 一个文案只讲一件事：状态用「图标 + 文字」，动作按钮用动词短语（创建房间、申请加入、撤回申请、结束房间）。
- 错误文案见 §8（必须写清发生了什么 + 下一步点哪里）；面向用户的失败不提「后端 / 环境变量 / README」等开发信息。
- 数字与时间：等宽字体（`.mono`、`tabular-nums`），时间用本地格式。
- 品牌与专名大小写固定：`Learning Guide`、`LiveKit`、`Lucide`。
- **情绪化文案只在等待页用**（温暖感），且保持短句、第一人称、不卖萌、零 emoji：例「你已经在门口了，房主看到就会开门」「房主通常很快处理」。交流页、等待页的次要文案与列表页保持中性、工具语气。

## 11. 图像与资产规范

- **来源与许可**：只允许公有领域（PD）、CC0 或本仓库自产素材；每件资产在 `docs/03-decisions/r001-adr-0010-visual-assets.md` 或本页登记「来源文件、许可、处理方式、体积」。来源不明的图一律不用。
- **统一处理管线**（暗色底上不出现矩形边界）：裁切 → 灰度 → 压暗背景（gamma ≈ 2.5–2.8）→ 双色调（ink → 强调色）→ 遮罩四边收敛到 0 → WebP。
- **体积**：单张 ≤ 120 KB；首屏资产直接放 `frontend/public/`（不带 hash，便于替换），非首屏走 `src/assets/`。
- **可达性**：纯装饰图 `alt=""` + `aria-hidden`；有信息含量的图必须写 `alt`。
- **图片类视差统一用「固定容器 + 元素在容器内滑动」模型**：
  - 容器与元素**等宽**；容器顶略高于页面顶，容器底停在**下一个交互行（如筛选/操作行）上方并留 12~24px 空隙**（用区块间距减去空隙写进 `bottom`，不要写死高度）；`overflow: clip` 保证元素不越出；
  - 元素初始贴容器顶（页面最高位），位移 = `clamp(scrollY × AMPLITUDE, 0, 容器高 − 元素高)`，幅度 `AMPLITUDE` 必须单点可调；**幅度默认 0.35**（0.1 量级在几百像素滚动量下只有几十像素位移，等于白做），甜点区间 0.25~0.45；
  - 行程只由容器几何决定，**不得依赖页面/窗口高度**；承载页面必须有最小高度（否则窗口够高时页面不滚动、位移恒为 0）；
  - `prefers-reduced-motion: reduce` 时幅度减半（不关闭），仍保证位移可见；
  - 放大元素后必须复查是否产生横向溢出。
- 不引外部图床、不用 CDN（离线演示与证书风险，见 ADR-0008）。

## 12. 页面情绪取向与页面级令牌（r002）

三个页面各有职责与情绪取向（术语见 `docs/glossary.md`，口径来源 `docs/rounds/r002-livekit/redirect-04.md`）：

| 页面 | 路由 | 情绪取向 | 装饰清单（§11 的视差/图版、Canvas 流场、网格质感层） |
| --- | --- | --- | --- |
| 房间列表页 | `/` | 中性 | 适用 |
| 房间列表页 | `/` | 克制、工具感 | 适用 |
| **交流页** | `/rooms/:id/live` | **专注感** | **显式不适用**（零装饰；底色再暗一档） |
| **等待页** | `/rooms/:id/wait` | **温暖感** | 适用（但只保留柔和暖光，不叠加位移元素） |

### 12.1 专注感（交流页）

- **单焦点**：说话者/共享者主格，其余窄缩格；非焦点格降饱和 `--live-focus-dim`（默认 0.35）、亮度 −12%；焦点格上缘 2px `--accent` 强调线。
- **界面会退场**：静默 `--live-chrome-idle-seconds`（默认 30 秒）后顶部状态条与底部控制条淡至 `--live-chrome-idle-opacity`（默认 0.45）；指针移动 / 键盘聚焦 / 有人说话立即恢复。
- **零装饰**：不加载 Canvas 流场、网格质感层与图版；不做背景渐变动画。
- **信息面极小**：44px 状态条 + 悬浮控制条（图标 + tooltip，无文字标签）；管理动作收进默认收起的抽屉。
- **反馈**：成功类反馈用状态条微亮，不弹 toast（只有失败弹）。
- **控制坞**：设备组 + 分隔线 + 离场组三段；按钮带文字标签与状态文字（`已开` / `已关` / `已静音`），开麦有电平条；离场用描边 + 二次确认 + 不绑快捷键（详见功能页 F-16 的防呆清单）。快捷键：`M` 静音、`V` 摄像头、`Esc` 取消/收起。
- **离场组的角色分岔（r003）**：房主位是「结束房间」——同一尺寸与位置，只用更强的危险色描边与对比区分（`--live-end-border` / `--live-end-hover` 两个令牌，单点可调），**不做填充**以免引诱误点；其他人位是「离开」（`--danger` 三成透明描边）。

### 12.2 温暖感（等待页）

- **暖色只做点缀**：`--wait-warm`（默认 `#f0b27a`）用于强调线与当前步骤；`--wait-warm-soft`（默认 10% 不透明）做自左上的径向光；**不做整页米色底**。
- **呼吸而非转圈**：`--wait-breathe-duration`（默认 6s）、幅度 4%；禁用 spinner 与进度百分比（处理时长不可知）。
- **状态可见**：三步时间线（已提交 / 等待房主批准 / 进入房间），当前步暖色微亮；获批后暖色转 `--accent` + 「可以进去了」，`--wait-autoenter-delay`（默认 1.5s）后自动进入。
- **可撤回可返回**：次级操作常驻。

### 12.3 参数集中区（单点可调，写在 `frontend/src/styles/global.css`）

```css
:root {
  /* 交流页 · 专注感 */
  --live-tile-radius: 16px;
  --live-stage-gap: 12px;
  --live-focus-dim: 0.35;         /* 非焦点格降饱和程度 */
  --live-chrome-idle-seconds: 30; /* 静默多少秒后界面退场 */
  --live-chrome-idle-opacity: 0.45;
  --live-focus-brightness: 0.88;
  --live-chrome: 44px;            /* 顶部状态条高度 */
  --live-surface: rgba(10, 12, 18, 0.72); /* 悬浮控制条底色 */
  --live-vignette: rgba(0, 0, 0, 0.45);   /* 舞台暗角 */
  --live-tint: rgba(124, 240, 196, 0.05); /* 顶部主题色光带 */
  --live-focus-glow: rgba(124, 240, 196, 0.16);
  --live-rail-width: 176px;               /* 右侧窄缩格条宽度 */
  /* 等待页 · 温暖感 */
  --wait-warm: #f0b27a;
  --wait-warm-soft: rgba(240, 178, 122, 0.10);
  --wait-breathe-duration: 6s;
  --wait-autoenter-delay: 1.5s;
}
```

### 12.4 降级（`prefers-reduced-motion: reduce`）

| 页 | 降级后的表现 |
| --- | --- |
| 交流页 | 取消一切位移与呼吸；焦点切格瞬时完成；界面退场只保留不透明度变化 |
| 等待页 | 呼吸光静止（保留暖色）；时间线与文案不做逐句淡入；自动进入仍生效（属状态变化，非动效） |
