## 1. 目的

1. **修**两处「两端不同步 / 状态不真」的界面缺陷（麦克风徽标、房间人数与待批数）；
2. **改**侧边栏个人信息的呈现形态（改成点击 / focus 才展开的浮窗，浮窗文字走哲学语句）；
3. **调**首屏《思想者》图版的初始位置（向下约 10%）；
4. **清点并处置**前面几轮登记的前端优化项（能做的做掉、已消失的关闭、欠账补齐）。

你另附三项前端优化（方向由你、细节我定）：① 个人信息改点击/focus 浮窗 ② 浮窗文字换成哲学语句 ③ 图版初始位置下移约 10%。细节取舍见 ADR-0017。

## 3. 边界

- **做**：`ParticipantTile`（麦徽标）、`useDataChannel` 新增 topic + 三个刷新触发点（进房/重连、窗口聚焦/可见性、30 秒兜底）、`RoomLivePage` 动作后广播、`SideBar` 个人信息浮窗 + 语录池、`global.css` 图版位置令牌与浮窗样式、`AGENTS`/模块页/功能页回填。
- **不做**：后端接口与数据模型零改动（`lg.roster` 只加速，HTTP 落库仍是唯一真相）；成员抽屉不加麦标（Q3）；状态条不加在场数（Q5）；举手/焦点/共享不进消息列表（上轮已定）；不动 LiveKit 权限类能力（静音他人等）。

## 4. 验收条目

| # | 条目 | 证据等级 |
| --- | --- | --- |
| E1 | A 未静音时 B 侧格子**不显示**麦徽标；A 静音后 B 侧出现麦徽标；A 取消静音后消失（双向各一次） | S（双浏览器真机） |
| E2 | 麦徽标状态来源 = `participant.isMicrophoneEnabled`（不依赖摄像头有无）：无摄像头但开麦 → 不显示 | S |
| E3 | 两端人数一致：A（房主）界面批准后 **≤2 秒** 内 B 端状态条同步为同一数字（不刷新页面、不聚焦） | S |
| E4 | 门牌「待批 N」与人数同批刷新（B 端 ≤2 秒） | S |
| E5 | 兜底：推送不可用（注入：不广播）时，30 秒轮询仍能把两端拉平 | S（注入级） |
| E6 | 个人信息：默认不展示邮箱 / id / 注册日期；点击头像行或键盘 focus + Enter 才出现浮窗；Esc 与点击外部关闭；`aria-expanded` 正确 | S |
| E7 | 浮窗内出现**一句**哲学语句（带作者），同一天内稳定、跨天变化；语录为真实语录（12 条池） | S + J（人工看文案） |
| E8 | 图版初始位置下移：同视口同滚动位置的「图版上沿」比改动前低约 50px（≈ 容器高 10%），滚动行为与行程仍正常 | S（DOM 量测 + 截图） |
| E9 | 原生 `alert/confirm` 仍为 **0 处**；首页筛选条仍在首屏内（防回归） | S |
| E10 | 门禁：`pytest` / `smoke` / `tsc` / `build` 全绿 | S |
| E11 | 名言按 **场景化 + 每次进入随机** 铺开；覆盖 A 段 11 处（含 404）；**替换**引导性解释文字，保留状态事实与功能文案 | S |
| E12 | 视觉/操作引导代偿：被删掉引导文字的位置都有可见入口或视觉承担（首页空态「创建房间」按钮、请先登录「去登录」、筛选空态「清空筛选」、等待页进度条、顶栏登录入口、404「回房间列表」） | S（DOM 断言 + 截图） |
