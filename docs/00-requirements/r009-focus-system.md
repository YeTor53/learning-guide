## 1. 需求（R）

| # | 需求 | 现状 |
| --- | --- | --- |
| R0 | **变化必须平滑且不反直觉**：进出/焦点切换/共享/缩放都要有动效，且不能出现瞬移、乱序、焦点乱跳（见 `motion-design.md`） | 现为直接跳变 |

## 2. 口径与边界

- **优先级不变**（ADR-0014 保留）：共享 > 手动焦点 > 说话者自动焦点 > 自己；本轮的 ADR-0021 只覆盖**布局算法**与**焦点权限**。
- **自动焦点保留**：说话者会自动获得焦点（画面跟随），手动焦点优先于它。
- **闪烁是纯视觉**：`prefers-reduced-motion` 时改为静态描边（不闪）。
- **声波用 LiveKit `audioLevel`**：不引入 Web Audio；静音或未发布音频时电平恒为 0（无声波）。
- 焦点事件全部 **HTTP 落库为唯一真相**，DataChannel 只做加速（沿用既有口径）。
- 房间结束后：焦点/举手/申请均不可再操作（409 `ROOM_ENDED`），只读展示最后一次状态。

## 3. 验收条目（E）

| # | 条目 | 证据 |
| --- | --- | --- |
| E0 | 变化动效：终点误差 ≤1px、过渡时长为 `--stage-move-ms`、无瞬移、交替说话 30 秒焦点切换 ≤3 次 | `getAnimations()` + 采样序列 + 脚本 |
| E1 | 均分布局：2/4/6/8 人四档，格子面积相对差 ≤ 5%、无横向滚动、区域铺满率 ≥ 90% | 真机截图 + `getBoundingClientRect` 量测 |
| E2 | 焦点格**面积份量 ≥ 1.35×**（实测 1.40×；多行多列时宽高各 1.4×，单行/单列时一维 1.4×） | 量测 + 截图 |
| E3 | 举手格持续闪烁（3px 强调色呼吸 1.2s）；减少动效时停摆 | DOM/CSS 断言 + 截图 |
| E4 | 举手 → 管理点「给焦点」→ 焦点变该人**且该人举手被清** | 用例 + 真机 |
| E5 | 「强制放下手」回归不坏（Host/Moderator 可操作他人） | 既有用例 |
| E6 | 房主点「取得焦点」→ 自己成焦点（1 次请求，无审批） | 用例 + 真机 |
| E7 | 协管点「取得焦点」→ 生成申请（pending）；**本人不出现批准按钮** | 用例 + DOM |
| E8 | 另一管理身份批准 → 协管成焦点；拒绝 → `rejected` 且焦点不变 | 用例 |
| E9 | 焦点者看到「退出焦点」（替换举手）；点击后焦点清空 | DOM + 用例 |
| E10 | 房主举手键默认文案「取得焦点」；协管为「申请焦点」；参与者为「举手」 | DOM 断言 |
| E11 | 麦克风悬浮键有声波环，随 `audioLevel` 变化；静音/未发布时归零 | 真机量测（数值范围）+ 截图 |
| E12 | 门禁：`pytest` / `smoke` / `tsc` / `build` 全绿；文档同步 | 门禁输出 |
