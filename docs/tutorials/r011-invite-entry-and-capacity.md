本页讲两件与「进房间」有关的事：**拿到邀请码怎么进去**（r011 补齐入口与未登录闭环），以及**房间满员时会发生什么**（r011 起满员会清掉待批申请）。其它房间能力见 `r004-room-extras-demo.md` / `r005-capacity-and-events.md` / `r010-transcription-user-guide.md`。

## 1. 拿到邀请码的两种进法

| 你手上有什么 | 怎么进 |
| --- | --- |
| 一整条链接（房主点「复制链接」给的，形如 `http://localhost:5173/join?code=zqddjt`） | 直接打开 → 页面已经带好码 → 点「加入房间」 |
| 只有 6 位码（别人口头念的、截图上抄的） | 打开站点 → **顶栏「邀请码加入」** → 在输入框里填码 → 点「加入房间」 |

两者进的是同一个地方；邀请码**最长 1 分钟有效**、默认 1 次可用，过期或次数用完会明确提示。

## 2. 还没登录就打开链接会怎样

1. 你会看到 `/join` 页面，按钮写着 **「去登录并加入」**；
2. 点它 → 跳到登录页（码会带过去）；
3. 登录（或注册）成功后**自动回到刚才那一页，并自动用这个码加入房间** —— 不用重新输码、也不用再点一次。
4. 如果码已经过期/被别人用掉，回来自动加入会失败并显示服务端原因，这时找房主重新生成一个。

## 3. 房间满员时会怎样（r011 新口径）

- **申请时满员**：提交申请直接得到「房间已满（上限 8 人）」提示，不会进等待室；
- **申请时没满、后来满了**：房主批准时会被容量挡回；这时房里**所有还在等待中的申请会被一起自动拒绝**，房内聊天栏出现一条系统消息（「房间已满（上限 8 人），N 条待批申请已自动拒绝」）；
- 你在等待室会看到「这次没能加入：房主没有批准，或房间已满被系统自动拒绝」，可以点「重新申请」（名额空出来就能再进）。
- 为什么会这样：本仓口径是**人数按本库在册成员**算（ADR-0016），满员即不再接收新成员；让申请一直挂着只会让人白等，所以满员那一刻就清账。

## 4. 演示前要准备什么

- 邀请码：房主在交流页右侧抽屉「**邀请**」tab → 选时长（30/60 秒）与次数 → 生成 → 复制链接。
- 想演示「未登录闭环」：用**无痕窗口**打开复制的链接（无痕默认未登录），就能看到「去登录并加入」这条路径。
- 想演示「满员自动拒」：用 8 个账号把房间填满（在册 8/8），再让第 9 个账号申请。

## 5. 常见疑问

| 问题 | 回答 |
| --- | --- |
| 顶栏的「邀请码加入」为什么一直在？ | 它就是通用入口：任何有码的人都能自己进来，不依赖别人把链接转发给你 |
| 满员后我再申请，会一直排队吗？ | 不会。满员那一刻房内待批申请会被自动拒绝并留一句系统消息，避免无限等待 |
| 被自动拒绝了会不会看不到原因？ | 等待页会写明「房主没有批准，或房间已满被系统自动拒绝」，房内聊天栏也有对应的系统消息 |
