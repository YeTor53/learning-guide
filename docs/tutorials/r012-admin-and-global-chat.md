前置：服务已起（`dev.bat`）、数据库已迁移（`python backend/scripts/db_init.py --seed` → `schema_migrations 12`）。
演示超管账号：`admin@example.com`（口令同其它演示账号 `demo1234`；也可用 `python backend/scripts/grant_superadmin.py --email <你的邮箱>` 把任意账号提为超管）。
本页只讲**怎么用**；实现与口径见 `docs/02-modules/r012-superadmin-console{,-features}.md`。

## 1. 大屏：所有人的公开聊天

1. 打开 http://localhost:5173 → 顶栏右侧点「**大屏**」→ 面板从右滑出（Esc 或点 × 收起；下次打开记得状态）。
2. 未登录时输入框是禁用的，面板底部给「去登录」；登录后输入一句话 → 回车或点「发布」。
3. 另开一个浏览器（另一个账号）同样打开「大屏」：**不用刷新**，几秒内会出现你刚发的那条（SSE 推送；断线时最多晚 30 秒，靠轮询兜底）。
4. 每条消息作者名后的小绿点 = 那个人**当前在线**（60 秒一次心跳，超过 120 秒没心跳就不亮了）。

排查：
| 现象 | 原因与处理 |
| --- | --- |
| 面板打不开 | 顶栏按钮在**常规页面**才有；交流页（`/rooms/<id>/live`）不挂这个面板（那里已有右侧抽屉） |
| 发了没反应 | 未登录会被禁言（输入框禁用）；发太快会提示「发得太快了」，内容不会丢，稍等再发 |
| 别人看不到 | 面板是公开面，不需要进房；若一直不出现，看一眼后端控制台是否在跑（SSE 断线靠 30 秒轮询兜底） |

## 2. 管理后台：房间 / 用户 / 纪要 / 审计

1. 用 `admin@example.com` 登录 → 侧边栏出现「**管理后台**」（普通账号看不到这一项）。
2. 「房间」分区：搜房间名或房主名 → 对**别人的房间**点「结束」（房间转已结束，房内聊天栏出现「管理员结束了房间」）→ 点「纪要」重生讨论纪要 → 点「删除」→ 行内出现「确认删除？不可恢复」，确认后房间从列表消失。
3. 「用户」分区：点「只看在线」筛出有心跳的人；「最后活跃」列显示他们最后一次上报的时间。
4. 「审计」分区：上面每个动作各一条流水（操作人 / 动作 / 对象 / 摘要）；**删除后流水仍在**（摘要是删除前的房间标题）。
5. 「纪要」分区：全站纪要列表（房间 / 状态 / 模型 / 字数 / 更新时间）。

## 3. 隐身：管理员在场但看不见

1. 普通账号建一间房（`capacity` 默认 8），把房间填满（或找一间已满的房）。
2. 用 `admin@example.com` 打开该房 → **进得去**（普通账号会被挡在门外，提示不在房间中）。
3. 看两端：普通账号的成员列表**没有**管理员、人数**不增加**、舞台**没有**他的格子；管理员自己界面控制坞显示「管理视角 · 隐身」，**没有**麦克风/摄像头/共享控件。
4. 管理员点「结束房间」或抽屉里「移出成员」→ 动作照常生效，并在房内留下系统消息。

## 3.5 不想手点？一条命令验隐身

```
python backend/scripts/verify_r012_superadmin_invisible.py
```
它会自己起两个隔离 Chrome、各登一个账号进同一间房，把「成员看不到超管」从**界面**（舞台格数 / 在册人数 / 成员抽屉）
和 **LiveKit 服务端**（参与者 `hidden=true`、禁止发布）两侧一起验掉，末尾打印 `PASS 17/17`；用完自己关浏览器、自己清理访问记录。
（加了 `--keep-chrome` 会把浏览器留着，方便你自己接着看。）
