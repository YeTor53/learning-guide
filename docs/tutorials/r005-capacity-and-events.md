房内四件事（群聊/举手/焦点/共享）看 `docs/tutorials/r004-room-extras-demo.md`；本页只讲「人数」与「房间事件」。

## 1. 上限数的是「名额」，不是「此刻在线人数」

- 容量 8 的意思是：**本场最多批准 8 个人**。房主批准一个，就占一个名额。
- 所以会出现「列表卡写着 `8/8 已满`，但屋里只有两三个人」—— 那是名额占满了，不是人都在线。
- 谁此刻在线，去抽屉「成员」看：标「在房间里」就是在线。

## 2. 满了会怎样

| 你做什么 | 会看到什么 |
| --- | --- |
| 满员时点「申请加入」 | 立刻被拒：房间已满（上限 8 人）。**不会**进等待室 |
| 你是房主，满员时点「批准」 | 也会被拒（防止名额被撑爆）；这条申请会留在「待批」里，你可以手动拒 |
| 你已获准（在册），房间满了再进来 | **能进**。上限只管「新占名额」 |
| 想腾名额 | 让已获准的人「离开」，或房主把他「移出」—— 名额立刻释放 |

## 3. 消息列表里多出来的灰字（系统消息）

「讨论」里会多出一些居中的灰字，那是房间事件，不是谁发的消息：

`某某 加入了房间` · `某某 离开了房间` · `某某 被移出房间` · `某某 成为房主` · `房间已结束` · `房间已满（上限 8 人），本次申请未通过`

它们和普通消息一起按时间排序，也会计入未读；翻「加载更早的消息」时同样能看到。

## 4. 常见疑问

- **为什么我看到 8/8 却还有人在屋里说话？** 上限是名额，不是人数；屋里的人可能是同一批已获准的成员。
- **为什么申请被拒了，房主还能看到一条「房间已满」的消息？** 那是给你和房主都留的痕：让房主知道门口有人被挡过。
- **被移出的人再申请还算原来那个名额吗？** 不算：移出即释放名额，他需要重新申请、房主重新批准。
- **房间结束后这些消息还在吗？** 在库里（房主可查；只读回看界面属后续里程碑）。
