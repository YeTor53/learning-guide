r009 重做了舞台布局（均分铺满 + 焦点加权）与动效（FLIP 平移）。本页教你怎么**量**它、在哪**改参数**、踩过的坑是什么；几何算法本身见 `docs/02-modules/r009-focus-system.md`，动效设计见 `docs/rounds/r009-focus-system/motion-design.md`。

## 1. 两个脚本：一个量几何，一个量动效

| 脚本 | 跑法 | 量什么 | 要不要起服务 |
| --- | --- | --- | --- |
| `frontend/scripts/verify-stage-geometry.mjs` | `node frontend/scripts/verify-stage-geometry.mjs` | **纯函数几何**：给定区域与人数，算出每格矩形 → 面积差、铺满率、焦点份量、是否重叠 | **不用**（纯 Node，无浏览器） |
| `frontend/scripts/verify-stage-motion.py` | `C:\ProgramData\miniconda3\python.exe frontend/scripts/verify-stage-motion.py` | **真机动效**：真浏览器 + LiveKit 房间里的实际帧序列 → 位移、单帧最大步长、动画时长、终点误差；顺带跑一遍邀请/焦点/纪要流程并截图 | **要**（后端 8000 + 前端 5173） |

依赖口径：几何脚本用仓库既有 Node；动效脚本用**本机 conda base 已装的 Playwright**（`C:\ProgramData\miniconda3\python.exe`），**不往仓库里加依赖**。截图与报告落 `%TEMP%\lg_r009.5\`（与 r004 起既有做法一致：证据留本机临时目录）。

## 2. 动效脚本在量什么（判据）

- **位移**：目标格中心点从第一帧到最后一帧的位移（`moved_px`）。
- **无瞬移判据**：`max_step_ratio = 单帧最大位移 / 总位移`。FLIP 是连续平移，比值应当明显小于 1；若某一帧就吃掉大部分位移，就是"瞬移"。
- **过渡时长**：逐帧读 `element.getAnimations()` 的 `duration`，应与令牌 `--stage-move-ms` 一致。
- **终点误差（settle）**：动画最后一帧的格子中心 vs 动画结束 200ms 后的静止位置之差 —— 理想为 0，判据 ≤1px（防止"动画完再跳一下"）。
- **重叠**：所有格子两两求交，应为 0 对。

## 3. 参数在哪改（都在一处）

`frontend/src/styles/global.css` 的 `:root` 令牌段（改一处即生效，无需动组件）：

| 令牌 | 现值 | 作用 |
| --- | --- | --- |
| `--stage-move-ms` | `240ms` | 布局变化时格子的 FLIP 平移过渡 |
| `--hand-blink-ms` | `1.2s` | 举手格边框呼吸闪烁周期（`prefers-reduced-motion` 下停用） |
| `--mic-pulse-ms` | `320ms` | 麦克风声波竖条的刷新节奏 |
| `--tile-fit` | `cover` | 格子内视频的填充方式 |

几何权重（焦点 1.4×、行列划分）在 `frontend/src/components/live/stageGeometry.ts` 的纯函数里，改完先跑几何脚本看数字。

## 5. 三条踩坑（都是本轮实测撞到的）

1. **`permissions` 之外，别加 `--use-fake-ui-for-media-stream`**：它会自动批准麦克风权限，于是默认"麦克风开"的发布真的发出去（实测 `isMicrophoneEnabled=true`）。只给 `permissions=["camera"]`，麦克风发布请求会被拒 → 全程无音频（符合仓库纪律「不发布假麦」）。
2. **API 请求的 origin 要与页面一致**：用 `context.request` 注册时打 `http://127.0.0.1:8000`，Cookie 挂在 `127.0.0.1`，而页面在 `localhost:5173` → 页面内所有请求 401（"请先登录"）。统一用 `http://localhost:8000/api` 即可（Cookie 不带端口）。
3. **要触发布局变化，得用"人会变"的事件**：给某个参与者开摄像头**不会**改变格子数（每人在场就有一格）；真正触发重排的是**加入 / 离开 / 焦点切换**。而**直调 HTTP 焦点接口不会广播**，本端界面不会重排 —— 要测焦点切换得走 UI 点击（走 `focus.setFocus` + DataChannel 广播）。
