## 0. 你需要什么

- 两个浏览器窗口（其中一个用**无痕**），各自登录一个账号，都进**同一个房间**；
- 想练屏幕共享的那一边，用**你平时用的浏览器**（无痕窗口常常不给共享权限）。

房间页长这样：中间一大格是**焦点格**（此刻被放大的人），右边一列是**缩格**（其他人），底部是**控制坞**，右上角「讨论与成员」是**抽屉**。

## 1. 群聊（抽屉「讨论」）

1. 点右上角「**讨论与成员**」→ 默认就在「**讨论**」页签；
2. 输入框里打字，**回车发送**、**Shift+回车换行**（上限 500 字，右下角有计数）；
3. 另一边不打开抽屉也能看到：抽屉按钮上会出现**未读数字**，点开即清零；
4. 聊天记录跟着房间走：刷新页面、退出再进，都能看到（自动拉最近 50 条，更早的点「加载更早的消息」）。

> 发不出去时：气泡会标红并出现「**重发**」——说明消息没落库，点一下重发即可（不会丢你的字）。

## 2. 举手

1. 控制坞左数第二颗「**举手**」→ 按钮变「**放下手**」并高亮闪一下；
2. 房主/协管那边：抽屉「讨论」顶部出现「正在举手：某某」，旁边有「放下 某某」；
3. 自己放下：再点一次「放下手」；房主放下你：你的按钮会自己回到「举手」。

## 3. 焦点发言（房主/协管的操作）

1. 抽屉切到「**成员**」页签，找到那个人，点「**给焦点**」；
2. **两个浏览器会同时**把那个人放到焦点格：他那边显示「焦点 · 你」，你这边显示「焦点 · 某某」，状态条上也会写「焦点 某某」；
3. 想收回：同一行按钮变成「**取消焦点**」，点一下就回落（回到「谁在说话看谁」）。

> 什么情况焦点会自己失效？那个人**不再是房间成员**（离开/被移出）时会立刻回落，并提示「焦点已失效」3 秒；只是**暂时掉线**的话，焦点格保留并显示他的头像块。

## 4. 屏幕共享

1. 控制坞「**共享屏幕**」→ 浏览器弹出选择框，选一个**窗口或整个屏幕**（建议选窗口，别人看得清）；
2. 你的画面会占据焦点格（带「共享 · 你」徽标），你自己在舞台右下角有「停止共享」；
3. 停止：自己点「停止共享」；或房主/协管在成员行点「**请求停止共享**」——你会看到提示并自动停下（这是**协作式**，不是服务端把你踢下麦）。

> 只共享**画面**，不共享系统声音（否则会与麦克风互相回授）。

## 5. 两人对练脚本（照着做一遍就都会了）

| 步 | 这边做什么 | 另一边应看到 |
| --- | --- | --- |
| 1 | B 在「讨论」发「我先补充一句」 | 1 秒内出现同一条 |
| 2 | B 点「举手」 | 抽屉「讨论」顶部出现「正在举手：B」 |
| 3 | A（房主）点「放下 B」 | B 的按钮回到「举手」 |
| 4 | A 在「成员」里给 B「给焦点」 | 两边焦点格都变成 B |
| 5 | B 点「共享屏幕」并选窗口 | A 的焦点格换成 B 的共享画面 + 「共享 · B」 |
| 6 | A 点「请求停止共享」 | B 自动停止并看到提示 |
| 7 | A 刷新页面 | 消息、举手、焦点与刷新前一致 |

## 6. 看不见 / 没反应时先查这五条

| 现象 | 先查 |
| --- | --- |
| 聊天里没有别人刚发的消息 | 对面的消息是不是发在**同一个房间**；状态条是否「已连接」；点一下抽屉里的「加载更早的消息」 |
| 举手了但房主没看到 | 房主抽屉是否停在「讨论」页签；他那边状态条是否「已连接」 |
| 点「共享屏幕」没反应 | 你用的浏览器是否**无痕/受限**（换普通窗口）；系统是否弹了权限框被忽略 |
| 焦点给了但不是两端都变 | 对面是否**还在房间**（不在册会失效）；刷新一下两边页面 |
| 重连中按钮全是灰的 | 正常：断线时所有操作按钮都禁用，等状态条自己回到「已连接」 |

## 7. 常见疑问

- **聊天只在房间里看得到吗？** 是。房间结束后历史仍在库里（房主可查），但这轮还没有「结束后回看」的界面（那是下一个里程碑）。
- **一次能有几个人？** 8 人（含房主）。满员时新申请会提示房间已满。
- **能撤回/删除消息吗？** 不能（本轮不做编辑与撤回）。
- **同一个人能同时开两个窗口吗？** 不能：同一账号在别处进入会把旧的那边断开（提示「同一账号已在别处进入本房间」）。
