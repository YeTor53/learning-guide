## 背景

用户要求「在大标题右侧加一个随网页上下移动有稍微位移的思考者雕像（图片）」：需要一张**真实的**罗丹《思想者》图片、放在首屏大标题右侧，并随滚动产生轻微位移。

约束：① 素材必须可商用/无版权风险（本仓库可能公开）；② 页面是暗色编辑风，图片不能出现明显的矩形边界；③ 不引入新的运行时依赖（不引动画库、不引图片处理库到前端）。

## 决策

1. **素材**：Wikimedia Commons 上克利夫兰艺术博物馆（Cleveland Museum of Art）藏《思想者》藏品照，**CC0**（公有领域贡献），原图 1920×2275。
   来源文件：`Auguste_Rodin_-_The_Thinker_-_1917.42_-_Cleveland_Museum_of_Art.tif`（Commons 缩略图，取宽 1400）。
2. **处理管线**（离线用 Pillow 跑一次，产物入库、脚本不入库）：
   裁掉台座与空档 → 灰度 → gamma 2.75 压暗中灰背景 → 双色调 `ink(7,9,13) → 强调色(196,255,236)` → 内缩圆角矩形遮罩 + 大模糊 + **四边线性衰减**（保证边界 alpha 严格为 0）→ 裁紧 → **水平镜像** → 缩放至 900×1094 → WebP q82。
   最终产物：`frontend/public/thinker.webp`（84 KB，带透明通道，已镜像）。
3. **放置与动效**（2026-09-18 按用户要求修订）：`.hero-thinker` 绝对定位在大标题右侧，宽 `clamp(262px, 28.75vw, 437px)`（**比首版大 25%**，`right: 0` 以避免横向溢出），`pointer-events: none`，`z-index` 低于正文。
   位移规则（2026-09-18 三次修订：**固定容器 + 图版在容器内滑动**，用户明确口径）：
   - **容器** `.thinker-box`：与图版**等宽**；**顶部略高于页面顶**（`--thinker-top: -110px` ≈ 顶栏 57px + 内边距 40px + 13px）；**底部停在「创建房间」那一行上方**（`--thinker-gap: 20px` 控制空隙，锚点写进 CSS：`bottom: calc(-1 * (var(--s-6) - var(--thinker-gap)))`）；高由上下锚点决定（实测 628px ≈ 图版高的 1.43 倍）；`overflow: clip` 保证图版永不越出容器。
   - **图版**：初始贴容器顶部（= 页面最高位）；向下滚动时按 `AMPLITUDE` 向下滑动，`offset = clamp(scrollY × AMPLITUDE, 0, 容器高 − 图版高)`；到达容器底部即停。
   - **行程**由容器几何决定，与页面/窗口尺寸无关：实测容器 628px、图版 440px → 行程 **188px**（图版下缘最低只到「创建房间」行上方 20px）。
   - **幅度默认 0.35**（2026-09-18 四次修订）：0.12 的幅度在几百像素滚动量下只有 50 来像素位移，观感「太不明显」；0.35 让图版在约一个首屏高度的滚动量内走完容器。
   - **可调参数**（改这几处即可）：`AMPLITUDE`（`ThinkerStatue.tsx`，默认 0.35，建议 0.10~0.60）、`--thinker-w` / `--thinker-aspect` / `--thinker-top` / `--thinker-gap`（`global.css` 参数区）、`--hero-min-h`。
   - rAF 合帧、滚动监听 passive；`prefers-reduced-motion: reduce` 时**幅度减半而非关闭**（AMP 0.12 → 0.06），保证仍能看到位移。
4. **可达性**：纯装饰图 → `alt=""` + `aria-hidden`，不参与键盘与语义；`title` 给出作品名与作者。

## 被否的替代方案

| 方案 | 为什么否掉 |
| --- | --- |
| **抠图**（只保留雕像，背景全透明） | 试了三种：大核模糊差分、饱和度（色度）键、边界连通域填充。候选馆藏照的背景都是**非均匀**的渐变摄影棚背景（四角亮度 58–250 不等），三条路径都留下明显光晕或把雕像暗部掏空（见处理日志的预览图）。要达到可用质量需要专门的抠图模型/服务，超出本轮成本 |
| 首版视差「向上 −14%、上限 ±48px」 | 方向与用户预期相反（往下滚它反而往上走），且上限过早触顶，观感上等于「没有偏移效果」；已按用户要求改为向下 10% + 下界约束 |
| 用 CSS `mix-blend-mode` 直接混照片 | 背景亮度接近正文灰，混合后整块发亮，等于把照片贴上去 |
| 引入 three.js / WebGL 把雕像做成 3D | 体积与离线风险大（ADR-0008 已否掉 WebGL 路径），且素材与建模成本更高 |
| 用 SVG 线描或剪影代替照片 | 视觉重量不够，用户明确要「图片」 |
| 用外链图片（Commons 直链） | 演示环境离线/证书不稳（本机证书库损坏），首屏会出现破图 |
| 视差用 `background-attachment: fixed` | 与「轻微位移」的诉求不符（那是整块固定背景），且移动端行为不一致 |

## 影响与待办

- 新增静态资产 `frontend/public/thinker.webp`（84 KB，已镜像）；前端代码新增 `components/ThinkerStatue.tsx`；`styles/global.css` 新增 `.hero-thinker`。
- 2026-09-18 修订记录：资材改为镜像并放大 25%（`right: -3% → 0`，修掉放大后 4px 横向溢出造成的横向滚动条）；位移方向与规则按用户要求重写（见上）。
- 2026-09-18 二次修订：下界改为与布局解耦的**虚拟值**（图版高度 × 35%，90–200px），并加裁剪容器把下界落在房间列表区顶线（允许图版被遮挡一部分）；同时修掉类名撞车（布局类 `.hero-thinker` 只给 `img`，外层用 `.hero-thinker-clip`，此前外层同时套到两个类导致量测到容器而非图版）。
- 2026-09-18 三次修订：改为**容器模型**（等宽、容器高 = 图版高 × 1.4、顶高于页面顶、底低于房间块底边、`overflow: clip`），行程由容器几何给出（实测 176px），幅度单点可调（`AMPLITUDE`）。
  四次修订：容器底由「图版高 × 1.4」改为**锚定「创建房间」行上方**（`--thinker-gap: 20px`），并把 `AMPLITUDE` 从 0.12 提到 0.35（用户反馈位移太不明显）。
  并定位「怎样都不会动」的两个根因：① `.hero` 之前没有最小高度，**窗口够高时首页整页不需要滚动** → 没有滚动就没有位移（现加 `--hero-min-h: min(88vh, 700px)` 保证任何屏幕高度下都有可滚动距离）；② 此前 `prefers-reduced-motion: reduce` 会**完全跳过**滚动绑定（系统关掉动画的用户永远看不到位移），现改为幅度减半。
- 风格指南新增 §11「图像与资产规范」（来源与许可登记、统一处理管线、体积上限、装饰图可达性、位移上限）。
- 换图流程：把新图按同一管线处理成 780×949 左右的带透明 WebP，覆盖 `frontend/public/thinker.webp` 即可，组件与样式无需改动。
- 未做：图片懒加载（首屏元素，按需加载反而更慢）；响应式多尺寸（窄屏用 CSS 缩放，未生成多套 srcset）。
