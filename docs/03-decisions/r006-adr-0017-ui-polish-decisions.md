本 ADR 只裁「界面怎么呈现 / 用什么机制同步」这类口径；实现细节见 `docs/rounds/r006-ui-sync-polish/design.md`。

## D1 麦徽标读**真实麦克风状态**，且只在静音时出现

- 事实源：`participant.isMicrophoneEnabled`（远端由 LiveKit 同步，实测 `true → false` 正确）。
- 呈现：**只图标 + `title`/`aria-label`「麦克风已静音」**（Q1=1「只在异常态显示」、Q2=2「不加文字」）。
- 取代：旧实现 `{!showVideo && <MicOff/>}` —— 图标实际挂在「有没有摄像头」上，导致没人开摄像头时人人恒显「麦克风未开」、静音与否完全不变。
- 代价：格子不再有「无画面」的暗示（无画面仍以头像块表达，语义不丢）。

## D2 房间名册/待批用 `lg.roster` 广播同步，HTTP 仍是唯一真相

- 机制：任一端做完房间动作（批准/拒绝/踢人/角色/移交/结束）后在 r004 那条可靠通道上广播 `lg.roster`；其他端收到即失效相关查询重取。
- 兜底：进房/重连、窗口聚焦、页面重新可见时刷新；再加 **30 秒**可见性感知轮询。
- 口径不变：**HTTP 落库为唯一真相，通道只加速**（ADR-0013 的沿用，不是新规矩）。
- 状态条数字口径保持在册（Q5=2，不加在场数）；「在场」只出现在成员抽屉。
- 替代方案与否决：①低频轮询（延迟 10~15 秒、请求恒定，不采用为主）②只在关键时刻刷新（会长时间不一致，不采用）。

## D3 个人信息改为点击 / focus 展开的浮窗，内容以「一句哲学语句」为主体

- 侧边栏默认只留一行（头像 + 名字），不再直接铺开邮箱 / id / 注册日期；点击或键盘 focus 才展开浮窗，`Esc` 或点击外部关闭。
- 浮窗 = 身份信息（名字 / 邮箱 / 加入日期）+ **一句哲学语句（带作者）** + 登出；语句**按日固定**（同日可复现、跨天变化），只收真实语录，池子单文件可替换。
- 理由：侧边栏是常驻区域，长期展示账号元信息既占位又无信息增量；浮窗是「需要时才看」，也顺带成为这个学习空间的一个小仪式。
- 代价：多一次点击才能看到邮箱；用 `title` 与「登出」按钮保留可达性。

## D3 修订（2026-09-19，按 redirect-02 批复）

- **替换而非并存**：引导性解释文字（11 处）由名言取代；**引导由视觉设计与操作入口承担**（被删文字的位置都留有可见按钮或进度视觉）。
- **场景化 + 每次进入随机**：每个位置映射到一个场景（`hero/learn/patience/meet/self/farewell`），从该场景标签组内随机取一句；不再「按日固定」。
- **池子扩到 46 条、分 7 组标签**，允许诗词与科学名言；**只写作者**、中文译句；用户不可干预（不提供「换一句」或开关）。
- 保留：状态事实句与全部功能文案（按钮 / 确认 / 报错 / tooltip / 表单 hint）。

## D4 图版初始位置下移约 10%（只改一个锚点）

- `--thinker-top` 由 `-110px` 改 `-60px`（窄屏 `-92px → -46px`）：即未滚动时图版上沿下移约 50px（≈ 容器高的 10%）。
- 容器底仍锚在「创建房间」行上方，位移行程自动缩短，`overflow: clip` 保证不出容器。
- 替代：改 `AMPLITUDE`（那是滚动行程比例，与「初始位置」无关，不采用）；改图版本体（成本高、与位置问题无关，不采用）。
